# 本地扩展与向量检索

## 如何联网搜索

在设置的模型板块选择联网检索服务。Tavily 需要单独申请搜索 Key，配置 DeepSeek 不会自动得到 Tavily 权限。助教可调用搜索并读取网页，随后按你的选择保存资料。搜索能力与 MCP 无关，已有 HTTP 搜索可以直接继续使用。

## MCP 是什么，现在怎么接入

MCP 让助教调用你授权的外部工具。在「设置 → 模型与接口 → MCP 服务配置」点击「添加服务」，选择本地进程 stdio 或远程 Streamable HTTP，填写服务地址或已安装程序的绝对路径，并选择工作区与课程范围。

核对程序来源后勾选信任，点击「连接并发现工具」，选择允许调用的只读工具，启用并保存。保存本身不会启动服务。随后可填写 JSON 参数，点击「直接测试工具」检查服务返回值；这个按钮不调用模型。回到相同工作区和课程范围，通过对话提出需要该工具的问题，助教可以自行选用工具，调用轨迹显示实际执行情况。

课程选择「全局对话」时仅在未锁定课程的对话开放；特定课程只向该课程开放。只有公开资料服务才勾选「公共资料（可跨课程）」。固定参数用于约束服务目录等参数，模型不能覆盖，但第三方服务仍须自行限制可读取的数据。

目前支持只读工具，不支持 OAuth 登录、旧版 SSE 或第三方写入工具。助教不能自行安装程序、注册服务或授予信任。需要 Bearer 或其他密钥时只填环境变量名称，不把密钥粘进命令、URL、参数或工具说明。桌面应用必须启动在能取得这些变量的环境中，终端临时变量不会自动进入从 Finder 打开的应用；缺少变量会在配置列表提示。

保存后返回服务列表，继续点击「添加服务」即可新增第二个、第三个服务。每个服务独立编辑、启停和删除，不需要覆盖已有服务。设置中的模型、联网、MCP、邮箱区域可折叠，邮箱当前仍未接通。

对话标题栏的工具选择器支持「自动」「禁用 MCP」和指定服务。自动仅提供当前授权范围内的工具；指定服务时只提供它自己的工具。服务被停用、删除或不符合当前课程范围时会明确提示不可用，不会改用其他 MCP。禁用 MCP 不会关闭内置的本地检索、日历和联网搜索。回答后的状态会区分“工具可用但本轮未调用”和“实际调用”。

没有配置服务时显示未配置，这是正常状态。SDK 已安装、连接测试成功、直接工具测试成功、模型成功调用是四个不同状态。若看不到「添加服务」，需要安装包含本轮扩展的新构建。

## 如何新增多个模型与智能体

在「设置 → 模型与接口 → 模型列表」点击「新增模型」，填写名称、唯一 ID、接口地址、模型名与密钥。保存后配置折叠回列表，可继续新增。然后在任务路由中把模型分别绑定到「速度优先」和「推理优先」，保存后对应任务使用所选模型；选择「沿用旧档位」继续使用原有配置。

编辑已有模型时密钥留空表示保留，勾选删除密钥才会清除。被任务路由引用的模型需要先解绑再删除。接口配置与智能体角色不同：新增助教在「设置 → 角色卡」的「新增 Agent」入口，角色可绑定技能与速度/推理档位。新增模型不会自动新增一个助教。

## 向量能否替代图谱

向量用于寻找意思接近的文字；知识图谱记录知识点、章节、关系和证据，两者可以配合。当前正式问答仍用全文检索，sqlite-vec 是独立本地实验，不会因选择设置项就自动启用。还需要本机 Embedding 模型生成向量，并完成检索质量验证。

## 原始材料是否会丢失

不会因为重建向量索引而改变原始资料。主库和课程文件保持原来的位置。向量索引可以重建，已经删除、改写或失效的记录会在返回前再次检查；新增材料需重建后才能参与向量实验。它不会自动改变掌握度或把未确认候选写进图谱。
