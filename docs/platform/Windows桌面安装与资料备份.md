# Windows 桌面安装与资料备份

MinDock 思泊提供独立的 Windows 10/11 x64 安装版。双击对应版本的 `MinDock-0.5.5-Windows-x64-mcp-candidate-<timestamp>-Setup.exe`，选择安装目录并完成安装，然后从桌面或开始菜单打开 MinDock。不需要账号、Python、Node 或手动启动服务。

## 个人资料

固定保存在 `%LOCALAPPDATA%\MinDock`，一般对应 `C:\Users\你的用户名\AppData\Local\MinDock`。菜单「资料 → 打开数据文件夹」可直接打开。

- `app`：数据库、模型配置、Hub、日志及维护记录。
- `StudyPal`：课程原材料、拆录笔记、知识产物。
- `LifePal`、`WorkPal`：其他个人工作区。

安装目录只放程序与运行环境。升级安装替换程序，个人资料保留；卸载也不主动删除个人资料。Windows 与 Mac、源码开发版各用独立目录，不会自动同步。

## 材料和模型

图片和扫描 PDF 使用随包离线 OCR。原始材料归档后可查看识别任务，确认候选后进入正式图谱与掌握度。单次上传最多 200 MiB；超过 100 MiB 的 PDF 先归档、暂缓自动解析。录音识别仍需另配语音工具或文字稿。

模型服务需要在「设置」填写自己的接口、模型和 Key。分享的安装程序只带公共初始化资料，不带制作者的模型 Key、对话或私人教材。联网搜索仍需要网络和可用搜索来源。

## 备份和恢复

选择「资料 → 备份个人资料」，应用会暂停后台服务，写出 ZIP，再重新打开。备份包含个人资料与对话，密钥会清除，桌面缓存和日志不进入备份。

选择「资料 → 从备份恢复」，选中 ZIP 后查看日期和数量，再确认恢复。恢复前保留当前资料副本；恢复后需检查并重新填写模型 Key。个人备份不要作为安装包发给同学。

## 便携版

解压 `MinDock-0.5.5-Windows-x64-mcp-candidate-<timestamp>-Portable.zip` 后双击 `MinDock\MinDock.exe`。整套目录必须保留，不要只移动 EXE。便携版同样使用 `%LOCALAPPDATA%\MinDock`，不是把个人资料放进便携程序目录。

## 当前验收范围

此版本在 Mac 上交叉构建，已检查 Windows 可执行文件、运行依赖、OCR 模型、包完整性及私人配置排除，并通过共享后台和桌面生命周期回归。尚未在 Windows 实机执行安装、点击、升级及卸载验收。

当前安装程序未做 Authenticode 签名，Windows 可能提示来源未验证。只在确认包来自可信来源、校验值一致时，按系统提供的单次允许提示操作，无需关闭全局安全保护。
