# Mac 桌面应用与资料备份

MinDock 思泊提供 Apple Silicon（M 系列）桌面安装版。打开 DMG，将 MinDock.app 拖到应用程序文件夹，再双击打开。以后直接从应用程序或 Dock 使用，不需要终端、浏览器地址或开发环境，也不需要注册平台账号。

## 资料保存在哪里

固定保存在 `~/Library/Application Support/MinDock/`。在顶部系统菜单选择「资料 → 打开数据文件夹」即可直达。里面包含 app 中的数据库与配置，以及各工作区的原材料、笔记和知识产物。

开发目录和安装版是两份独立资料，互不自动同步。更换应用文件不会删除此资料目录；不要为了更新版本而删除个人数据。

## 如何备份与恢复

「资料 → 备份个人资料」选择一个新的 ZIP 文件名。应用会暂时停止识别和对话，保存资料后重新打开。备份包含个人材料、图谱、日历、对话和 Agent/Skill，默认排除模型密钥。

「资料 → 从备份恢复」选择备份并确认。应用先校验文件和数据库，再保留当前资料副本，最后恢复选中的版本。恢复后请检查模型配置，重新填写密钥。备份属于个人恢复资料，包含隐私内容，不要当安装包发给同学。

## 上传后的识别状态

文件先归档，识别任务随后在后台处理。课程页可以查看排队、处理中、待确认、失败或中断状态；失败和中断可重试，处理中可取消。确认候选后，知识点进入同一套正式图谱和掌握度记录。

单个文件归档上限 200MB；超过 100MB 的 PDF 先保存、暂缓自动解析。此时请使用较小的章节文件。应用退出后不继续扫描或发提醒，下次打开可处理未完成任务。

## 模型与安装权限

桌面应用内置运行环境和本机文字识别，模型问答仍需在设置中配置模型服务。联网搜索依赖网络和搜索来源，不是安装后附送的离线模型。

本地签名版本尚未经过 Apple 公证，macOS 可能拦截来源未验证的安装包。这与是否有用户账号无关。仅在确认来源可信时，按系统「隐私与安全性」中的提示允许本次打开，不必关闭全局系统安全保护。
