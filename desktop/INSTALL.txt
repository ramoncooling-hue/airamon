MinDock 思泊 0.5.5 · Apple Silicon 桌面安装版

适用：M 系列 Mac，macOS 14 或更新版本。

1. 双击 DMG，把 MinDock.app 拖到 Applications（应用程序）。
2. 在应用程序里打开 MinDock。不需要注册或登录，不需要安装 Python。
3. 首次运行自动创建本机资料目录：
   ~/Library/Application Support/MinDock/
   菜单「资料 → 打开数据文件夹」可直接进入。
4. 在设置里填写你自己的模型接口和密钥，即可使用模型问答。
   数据库、教材、笔记、日历、图谱、Agent/Skill 和配置都留在你的电脑。
5. 关闭应用会关闭它自己的本地服务。升级只替换 .app，不要删除数据目录。
6. 菜单「资料 → 备份个人资料」保存恢复用 ZIP；备份不包含模型密钥。
   「从备份恢复」会先保留现有资料，再恢复选中的备份，完成后自动重开。
   这是你个人的恢复备份，包含私有材料和对话，不是发给同学的安装包。
7. 上传文件后可在课程页查看识别任务，失败或中断可重试，也可取消。
   候选由你确认后进入图谱和掌握度；已归档不代表已经完成识别。

本包采用本地临时签名，尚未经过 Apple Developer ID 签名与公证。
若下载后被 macOS 拦截，确认来源可信后，在「系统设置 → 隐私与安全性」
找到本次拦截并选择「仍要打开」，再确认打开。不需要关闭系统安全保护。
这与是否注册用户账号无关。

图片和扫描 PDF 使用内置 macOS 文字识别；普通 PDF/Word/PPT 支持文字抽取。
单文件归档上限 200 MB；PDF 超过 100 MB 会先归档并暂缓自动抽取，避免内存崩溃。
录音转写沿用可选的本机 Whisper 或同名 TXT/MD 转写稿，不内置大型语音模型。
联网搜索和云端模型需要网络，模型服务可能收取 API 费用。
此安装包不包含开发者个人文件、对话记录或 API Key。

日常使用：直接打开“应用程序”中的 MinDock，可保留在 Dock。
不需要运行开发启动脚本，不需要输入本地网址。开发目录的数据不会自动同步到安装版。
